# Common labels

These labels are added alongside, not in place of, existing repository-specific labels.

| Group | Labels |
| --- | --- |
| Type | `type:bug`, `type:feature`, `type:task`, `type:documentation`, `type:security` |
| Priority | `priority:P0`, `priority:P1`, `priority:P2`, `priority:P3` |
| Status | `status:triage`, `status:ready`, `status:in-progress`, `status:blocked`, `status:review` |
| Manual Claude Code | `claude:ready`, `claude:working` |

Priority meanings: P0 = urgent service or security impact; P1 = important; P2 = normal planned work; P3 = low priority. `claude:*` labels communicate manual-session state only; they do not trigger automation.
